# Laplacian Eigenmaps — Implementation and Exploration

A from-scratch Python implementation of the Laplacian Eigenmaps algorithm for nonlinear dimensionality reduction, following Belkin & Niyogi (2003). Tested on the Swiss Roll dataset.

## Background

Laplacian Eigenmaps embeds high-dimensional data into a lower-dimensional space by preserving local neighborhood structure. Unlike Isomap, which attempts to preserve global geodesic distances, Laplacian Eigenmaps only requires that nearby points in the original space remain nearby in the embedding. This makes it a locality-preserving method.

The algorithm works by constructing a nearest-neighbor graph from the data, optionally weighting edges with a heat kernel, then computing the graph Laplacian and using its smallest non-trivial eigenvectors as embedding coordinates.

## Implementation

### Files

- `laplacianEmbedder.py` — Core library with graph construction, Laplacian computation, and eigendecomposition.
- `swissRoll.py` — Experiment script that generates the Swiss Roll, runs the embedding, and produces visualizations.
- `requirements.txt` — Python dependencies.

### Pipeline

1. **Construct adjacency graph**: Build a symmetric k-NN graph using `sklearn.neighbors.NearestNeighbors`. Symmetry is enforced via `A.maximum(A.T)`, matching the paper's definition: an edge exists between i and j if i is a neighbor of j OR j is a neighbor of i. In `"weighted"` mode the graph stores Euclidean distances; in `"simple"` mode it stores binary connectivity.

2. **Apply heat kernel weights** (weighted mode only): Edge values are transformed from distances to similarities via `w_ij = exp(-d_ij^2 / t)`, where `t` is a user-specified bandwidth parameter.

3. **Compute the symmetric normalized Laplacian**: Given the weight matrix W and degree matrix D = diag(W·1), the unnormalized Laplacian is L = D − W. The implementation computes the symmetric normalized form L_sym = D^{-1/2} L D^{-1/2}.

4. **Eigendecomposition**: Solve L_sym v = λ v using `scipy.linalg.eigh`. The embedding uses eigenvectors corresponding to the smallest non-zero eigenvalues (indices 1 and 2 for a 2D embedding, skipping the trivial zero-eigenvalue eigenvector).

### Why L_sym instead of the generalized eigenproblem

The original paper solves the generalized eigenproblem Lf = λDf. An equivalent approach — shown in lecture slides by Dr. Guangliang Chen (SJSU, Math 253) — is to solve the standard eigenproblem on the symmetric normalized Laplacian L_sym = D^{-1/2} L D^{-1/2}. The two formulations share the same eigenvalues, and their eigenvectors are related by the transformation f̃ = D^{1/2} f. Since L_sym is symmetric, it can be passed directly to `scipy.linalg.eigh` without needing to handle the generalized case or risk the numerical issues that arise from explicitly inverting D.

## Results

The implementation successfully unrolls the Swiss Roll, producing a smooth color gradient in the 2D embedding that preserves the local ordering of points along the manifold surface. The eigenvalue spectrum shows the expected monotonically increasing pattern with a near-zero first eigenvalue.

Results are qualitatively consistent with Figure 2 of the paper but do not match exactly. The paper uses 2000 randomly sampled points but does not report the random seed, so identical reproduction is not possible. Shape differences (e.g., U-shape vs. flat strip) are expected — Laplacian Eigenmaps preserves locality, not global metric structure, and eigenvectors are only unique up to sign and rotation.

## Usage

```bash
pip install -r requirements.txt
python swissRoll.py
```

Key parameters in `swissRoll.py`:

- `n_samples` — Number of points sampled from the Swiss Roll (default: 2000).
- `n_neighbors` — Number of nearest neighbors for graph construction.
- `t` — Heat kernel bandwidth (used only when `method="weighted"`).
- `method` — `"weighted"` applies heat kernel weights; `"simple"` uses binary connectivity (equivalent to t = ∞ in the paper).
